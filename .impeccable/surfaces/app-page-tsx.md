## Direction contract

THESIS: This is the lobby directory board of the building where you're already serving your apprenticeship — not a SaaS landing page pitching a product. It refuses the hero-banner-plus-feature-grid arrangement every events tool ships.

OWN-WORLD: Palette — charcoal panel `#1f2326`, backlit cream `#f4efe3`, brushed rail grey `#8b8f94`, amber LIVE accent `#ffb23f`. Type — a condensed institutional sans for routed listing rows, paired with a warm slab for hand-set touches (stamps, personal marks). Components — routed listing rows prefixed with a listing code (№), backlit panel sections with visible seams/rivets, an amber "LIVE" tab for in-progress items, small hand-set personal signature marks beside names instead of generic avatar circles.

STORY: An apprentice lands here and reads it immediately as "this is my building's board," not a public marketing site — gated, specific, theirs. They believe this network is exclusively apprentices like them, scan live/upcoming listings, and the call to action is to find their name already waiting in the directory (sign up) or step back in as a returning name (log in).

FIRST VIEWPORT: Full-bleed charcoal panel photographed straight-on. Top rail holds the wordmark "COHORT" routed as its own backlit listing slot with a code (№ 001). Below, 3-4 real listing rows slide in as the hero content — live/upcoming events with programme tag, date, location, routed in the same backlit letter style, amber LIVE dot where relevant. Primary actions (Sign up / Log in) sit as two routed tabs at the bottom-right of the panel, like a building's labeled directory buttons, not a floating CTA.

FORM: Backlit office/campus lobby directory board. Index 7 of 7 ordered candidates, assigned by the roll (dice passed over my own top-ranked pick, "The Logbook," which stays recorded as an alternate). Seed key b41fd820.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.
